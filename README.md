# Pearkit Studio: downloads

Pearkit Studio is the desktop app for looking at the components of [Pearkit](https://github.com/peardrive/pearkit),
redrawing them, and proposing changes.

**[Download the latest version](https://github.com/peardrive/pearkit-studio-releases/releases/latest)** (a `.dmg` for
a Mac with Apple silicon).

## Install

1. Open the downloaded `.dmg`.
2. Drag **Pearkit Studio** onto **Applications**.
3. Open it from Applications. It is signed by Peardrive LLC and checked by Apple, so macOS opens it without a warning.

## Set up, once

Open **Settings** (bottom left):

- **GitHub:** sign in when Studio asks. The code is already on your clipboard: paste it on the page that opens.
- **AI:** paste the AI key you were given, then Save. It is kept in your Mac's keychain.
- **Updates:** paste the update invite you were sent, then Connect. From then on Studio updates itself.

The app holds no key and no shared space of its own: both come from whoever invited you.
